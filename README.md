# Архивация старых файлов при переполнении папки

Bash-скрипт, который следит за размером папки: если она превышает заданный порог, самые старые файлы упаковываются в архив и удаляются, пока размер не опустится до нужного уровня. К скрипту есть набор автотестов на виртуальном диске.

## Как работает `lab_main.sh`

1. Считает текущий размер папки и сравнивает его с порогом.
2. Если порог превышен, вычисляет целевой размер: заданный процент от порога (по умолчанию 70%).
3. Выбирает самые старые файлы так, чтобы их архивация освободила достаточно места.
4. Упаковывает их в `.tar.gz`. С переменной окружения `LAB1_MAX_COMPRESSION=1` используется максимальное сжатие `.tar.xz` (lzma).
5. После успешного создания архива удаляет исходные файлы.

Пороги можно задавать в удобных единицах (`500k`, `100m`, `2g`). Все шаги пишутся в лог с отметкой времени.

## Запуск

```bash
./lab_main.sh -d <папка> -t <порог> [-b <папка_для_архивов>] [-p <процент_удержания>]
```

Пример: если папка `logs` больше 1 ГБ, архивировать старые файлы в `/tmp/backups`, пока она не станет меньше 700 МБ:

```bash
./lab_main.sh -d logs -t 1g -b /tmp/backups -p 70
```

## Тесты

`lab_tests.sh` создает виртуальный диск (через `hdiutil`, поэтому тесты работают на macOS), наполняет его файлами и проверяет поведение скрипта:

| Тест | Что проверяет |
|---|---|
| T1 | архивация с gzip при превышении порога |
| T2 | архивация не запускается, если размер в норме |
| T3 | максимальное сжатие xz |
| T4 | обработка ошибки: папка для архивов недоступна |

```bash
./lab_tests.sh
```
